## What is npm?

- npm manages packages, but it is not node package manager.
- npm is a standard repository for all the packages.
- npm is a package manager, it will manage all the packages that we install in our system.

## Configuring our project

## What is package.json file?

- It is basically a configuration for npm, it keeps track of what version of the package is installed into our system.

## Why do we need package.json ?

- npm will take care of the packages, its dependencies, version. It will take care of this in the package.json file.

## What is a bundler?

- When we have a normal html, css file. Our whole code needs to be bundled together, whole code needs to be minimized, whole code needs to be cached, whole code needs to be compressed, whole code needs to be cleaned before sent to the production.
- A bundler helps to do all that thing.
- Webpack, parcel, VEET these three thing are bundlers. There have more bundlers other than this.

### What is the job of bundler?

- Bundler basically bundles your app, it packages our app properly, so that it can be shipped to production.
- When we use create react app, that create react app behind the scenes uses WebPack.
- In our project we are uninng parcel.

## What is package-lock.json?

- package-lock.json keeps track on exact verision that is installed.

## What is node_modules?

- node modules contains all the code that we fetched from npm.
- package.json is configuration for nopm, while node modules contain the actual data(dependencies).

## What is transitive dependencies?

- A dependency not directly installed, but required by another dependency.
- A package is depndent on other package and the other package is dependent on someother package it is called transitive dependency.
- A transitive dependency occurs when:
- Package A: directly depends on Package B.
- Package B: in turn directly depends on Package C.
