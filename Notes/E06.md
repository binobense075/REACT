# How webapps fetch data from backend?

- Two ways
- Page Load -> Api Call -> Render (Here unitill the api returns response we don't see any thing, after that we suddenly see the response, this is a poor UX)
- Page Load -> render -> Api call -> Re-render [This is a better approach(Better UX)]

# useeffect hook

- useeffect takes two arguments
- useEffect( ()=> {}, [] );
- first argument is arrow function(a callback function) and the second argument dependency array.

# WHen will the useEffect callback funcion called?

- This callback function will be called after the component renders.
- When the Component finished rendering, it will call the useEffect callback function.

# Why do we use state variable?

- Whenever state variable updates react triggers a reconciliation cycle(re-renders the component).

- React fiber is the new reconciliation process to efficiently manipulate the DOM.
- React fiber is making react fast.
