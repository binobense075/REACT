# TailWind

- postcss : tool for tranforming CSS with JavScript, tailwind behind the scenes uses postCss

- .postcssrc is the configuration for postcss
- postcss rc is uded to understand tailwind
- tailwind give class for every css
- tailwind css is lightweight
- when parcel bundle the website, it only include the css which is required
- if we use m-4 100 times it just take one time.
- Tailwind CSS generate styles on the Fly only for the classes that we actually use, this keeps our css lean and efficient.
