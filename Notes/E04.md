# What does it mean to have a unique key property?

- Each of the list items should be uniquely represented.
- Whenever you are looping on to any list/anything, we want to give a key.
  <Restaurant key={}>
- key is a reserverd word

## But Why? Why we need keys?

- Suppose I have 4 restro cards in the dom and a new restro card came in, without unique keys react will re-render all the restro cards, because doesn't know which is the new card added it will treat all the cards as same, with unique key react wiil only render the new card
- this is a huge opptimization.
- if we don't write keys it gives a big performance hit

- Note never use indexes as a key(react itself says that never use indexes as a key)
