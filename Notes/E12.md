# Redux

- If you building a large scale applictaion, where the data is heavily used, where a lot of read and write operations is happening in our react applications, if a lot of data is transferring between components then using redux is best.

- All the applications that are built using redux can be built without using redux also.

## React and Redux difference.

- React and Redux is not same. Redux is a seperate library, React is seperate.

## There are two libraries that redux team offers

- - React-Redux
- It's kind of like a bridge between react and redux

- - Redux-Toolkit

# Architecture of Redux ToolKit

## What is Redux Store

- Redux store is a Big JS Object and it is kept in a central global place.

### Slices

- To keep data seperate, we need logical partitions, these logical partitions are Slices.
- If you want to add cart data into the redux store, we will create a seperate slice for cart data.
- For user data we will create a user slice and for different data different slice.
- Intially the slice is empty array

### How to write data into the slice

- When we click the add button we can't directly modify the cart, instead it dispatches an action, and then calls the function and the function modifies the cart slice.
- This function is known as reducer.

- When we click the add button, it dispatches an action which calls the reducer function which modifies/updates the slice of the redux store.

### How to read data into the slice.

- Using a Selector.
- We use selector to read the data from the store and the selector will modify the react component.

- A selector is a hook inside the react.
- This hook will give access to the store.

# Configuring and Working with Redux

- First we want to configure our store using configureStore from @react/toolkit
- configureStore() will give us the store of our react application.
- next we want to provide the store to the applicaion.
- To provide the store to our app, we need Provider from react-redux.
- We want to pass the store as a props to the provider.The store takes the store that we are configuring using configureStore().
- So now we are provided the store to the applciation.
- If you want the small portion of the app to use redux we can just provide the app to the specific portion of the app.
- @react/toolkit RTK library is used to manage redux.
- react-redux is the bridge between react app and redux store.(providning redux to the app is react-redux job).

- using createSlice() we can create a slice.
- this function takes a configuration to create a slice.
- name, initialState, reducers(here we will write the reducer fucntions) "here we write reducer function corresponding to each actions", this reducer fucntion gets access to the state(initialState) and action , it will modify the state based on the action.\
- Note we are mutating our state directly over here.
- Now we will exports our actions and reducers.(the reducer function will map to an action)
- default export the reducer and named export the actions.

- after exporting the slice, we want to add the slice to the store(the store we created using configureStore())
- inside configureStore we have the mainreducer, this reducer is a combination of different small stores, for each slice we will have a reducer.
- we will import the cart reducer and then we configure it in the mainReducer inside the store.
- This reducer contains all the small/sub reducers in our app.

- if you want to read the state, we want to subscribe to the store using a selector.
- a selector is a hook inside react, useSelector hook comes from react/redux lib.
- this hook give the access to the store, it gives a callback function that has store data we want to get what protion we need.
- this selector helps us identify what protion of the store we need to read.
- Whenver the items will be modifes this will update.
- The selctor gives access to the whole store, we jjust want to subscribe to the small portion of the store.

- we can modify the state in the store dispatch, useDispacth is given by react/redux as a hook.
- whatever we pass inside the action it will go insode the reducer function action
- wherever you are dispatching an action it will take whatever data you are passing in, it will create an object and it will create a payload inside the object and it will add whatever data you have added to the object and it will take this object and pass it as a second argument in the reducer fucntion insde he slice.
