# More about useState and useEffect hooks.

## useEffect

- useEffect is called using two arguments, callback function and dependency array.

### When is this use effect called?

- useEffect is called after every render of that component.
- Every time the component renders useEffect will be called.
- But the dependency array changes the behaviour of the its render.
- It's not mandatory to put dependency array in useEffect, only callback function is mandatory inside useEffect.
- When we call useEffect without dependency array,it will render every time the component renders.

### What if there was an empty dependency array?

- If the dependency array is empty, then useEffect is called on initial render(just once).
- Default nature of useEffect is to be called after each render, but if we give a empty dependency array it will call just once.

### What if we put something inside the dependency array?

- Then it will be only be called when the dependency changes.
- Suppose if we give the dependency array a state varibale, every time the state variable updates the component re-renders, every time the state variable inside dependency array changes the useEffect is called.

## useState

### Best and Worst practices of useState Hook.

- Never create a state variable outside of the fucntional component.
- Use state has a specific purpose, it is used to create local state variables inside the funcitonal components.
- Try to call the useState on the top of the component.
- Never use or create a state variable inside a if else(this can create inconsistencies in the program), react official docs says never create useState inside a condition.
- Never create a state varibale inside a for loop or normal function.
- The state variables are meant to be created inside a functional components on the higher level.
