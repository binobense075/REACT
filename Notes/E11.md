# Props Drilling

- React has one way data flow.
- React is a one way data stream, the data is passed from parents to children, to their nested childrens.
- Data flows from one direction (from top to bottom).
- When the application is huge, passing data between components is complex.
- React has one way data flow.
- We want to pass the data through nested children, this concept is known as props drilling.
- Supposse we want to access the props in the bottom , we want to drill it through nested children.4

# React Contect
